## Stack

| Layer | Technology |
|---|---|
| Contracts | Solidity 0.8.26, Uniswap v4-core / v4-periphery, solmate |
| Testing | Foundry: unit, fuzz, stateful invariants |
| Automation | Reactive Network (Lasna) CRON + callbacks |
| Frontend | React 18, Vite, viem |
| Hosting | GitHub Pages, Vercel |
| Indexing | Blockscout logs API + RPC polling |
| Docs | Mintlify |
